# Шаги B–D: домен + VPS + плавающий IP + DNS (REG.RU / REG.Cloud)

Репозиторий уже на GitHub: `https://github.com/Redcross-msk/gadalka`

Делайте **по порядку**. После каждого большого блока напишите в чат результат (IP / домен).

---

## Блок 1. Купить (или выбрать) домен

### Если домена ещё нет

1. Откройте https://www.reg.ru и войдите в аккаунт.
2. В шапке найдите поле поиска домена (или https://www.reg.ru/domain/new ).
3. Введите желаемое имя, например `gadalka` или своё название проекта.
4. Выберите зону (`.ru` / `.рф` / `.com` — что свободно и удобно).
5. Нажмите **В корзину** → **Оформить**.
6. Срок: обычно **1 год**.
7. Оплатите.
8. После оплаты: **Личный кабинет** → **Домены** — домен должен быть в списке со статусом активен / делегирован.

### Если домен уже есть у вас на REG.RU

1. https://www.reg.ru → **Домены**.
2. Убедитесь, что домен виден и не истёк.
3. Запишите точное имя: например `мойсайт.ru` — это и есть `YOUR_DOMAIN.ru`.

**Запишите домен на бумаге/в блокнот.** Дальше везде только он.

## Блок 2. Создать облачный сервер (VPS)

1. Откройте облако: https://cloud.reg.ru или из кабинета REG → раздел **Облако / Cloud / Серверы**.
2. Нажмите **Создать** / **Создать сервер** / **Заказать**.
3. Параметры (как у МОСКАСТИНГа):

| Поле | Что выбрать |
|------|-------------|
| ОС | **Ubuntu 22.04** или **Ubuntu 24.04** |
| vCPU | **не меньше 2** |
| RAM | **не меньше 4 GB** |
| Диск | **от 40 GB** (SSD) |
| Регион / ДЦ | любой РФ, где дешевле / ближе |
| Сеть | приватная сеть облака (по умолчанию ок) |

4. Доступ: задайте **пароль root** или загрузите SSH-ключ. **Пароль сохраните.**
5. Имя сервера: например `gadalka-prod`.
6. Подтвердите создание и дождитесь статуса **Running / Работает** (2–10 минут).

Пока можете **не** открывать сайт по IP — сначала сделаем плавающий IP и DNS.

---

## Блок 3. Плавающий (публичный) IP

Зачем: у облачной машины часто есть только внутренний адрес. **Публичный плавающий IP** — тот, который пишете в DNS и по которому заходите с интернета.

1. В панели Cloud откройте раздел **Сеть** / **Networks**.
2. Найдите **Плавающие IP** / **Floating IP** / **Публичные IP**.
3. **Создать** / **Заказать плавающий IP**:
   - тот же **регион / ДЦ**, что у сервера (иначе не привяжется);
   - подтвердите заказ (почасовая оплата).
4. В списке появится IP вида `185.x.x.x` или `89.x.x.x` — **скопируйте его**. Это ваш `IP_СЕРВЕРА`.
5. Напротив IP нажмите **Назначить** / **Привязать к серверу** / **Associate**:
   - выберите сервер `gadalka-prod`;
   - сетевой интерфейс (обычно один) → **Назначить**.
6. Через ~10–60 секунд IP должен показывать статус привязан к вашей ВМ.

### Файрвол / группы безопасности

Откройте **Сеть → Security groups / Файрвол** (или настройки сервера → Firewall) и разрешите входящие:

| Порт | Протокол | Зачем |
|------|----------|--------|
| 22 | TCP | SSH с вашего ПК |
| 80 | TCP | HTTP + выпуск SSL |
| 443 | TCP | HTTPS сайта |

Источник: `0.0.0.0/0` (весь интернет) — нормально для публичного сайта.

**Проверка с ПК** (подставьте свой IP):

```powershell
ping IP_СЕРВЕРА
ssh root@IP_СЕРВЕРА
```

Если `ssh` спрашивает fingerprint — введите `yes`, затем пароль root.

Пока **не** ставьте Docker, если DNS ещё не готов — можно поставить и позже. Главное: SSH по плавающему IP работает.

Напишите в чат: `IP=185....` (ваш плавающий IP).

## Блок 4. Привязать домен к IP (DNS A-записи)

Официальная логика REG: https://help.reg.ru/support/dns-servery-i-nastroyka-zony/rabota-s-dns-serverami/kak-privyazat-domen-k-ip-adresu

1. https://www.reg.ru → войдите → **Домены**.
2. Кликните по **названию вашего домена**.
3. Вкладка **Управление**.
4. Блок **DNS-серверы и управление зоной** → **Изменить**.
5. В блоке **DNS-серверы** → **Изменить** → выберите **ns1.reg.ru** и **ns2.reg.ru** → подтвердите (**Да**).  
   (Если уже стоят ns1/ns2.reg.ru — ничего не меняйте.)
6. Блок **Ресурсные записи** → **Добавить запись**:
   - Тип: **A**
   - **Subdomain:** `@`
   - **IP Address:** ваш **плавающий IP**
   - **Готово**
7. Снова **Добавить запись**:
   - Тип: **A**
   - **Subdomain:** `www`
   - **IP Address:** тот же плавающий IP
   - **Готово**
8. Если есть старые A/AAAA на `@` или `www` с другим IP — **удалите** их, чтобы не конфликтовали.

### Проверка с ПК (через 5–60 минут, иногда дольше)

```powershell
nslookup ваш-домен.ru
nslookup www.ваш-домен.ru
```

В ответе Address должен быть **ваш плавающий IP**.

Напишите в чат: `домен=ваш-домен.ru IP=... DNS ок` (или «DNS ещё не совпал»).

## Блок 5. Запуск сайта на сервере (после IP + DNS)

Когда DNS уже указывает на IP (или хотя бы SSH по IP работает), агент выдаст **готовый блок команд** под ваши значения.

Кратко, что будет:

1. `ssh root@IP`
2. Установка Docker
3. `git clone https://github.com/Redcross-msk/gadalka.git`
4. Правка `Caddyfile` (ваш домен) + файл `.env` (секреты)
5. `docker compose build && docker compose up -d`
6. `docker compose exec app npx tsx prisma/seed.ts`
7. Открыть `https://ваш-домен.ru` и `/admin`

**Важно для SSL:** Caddy выпускает сертификат Let's Encrypt только если **A-запись домена уже смотрит на этот сервер** и открыт порт 80.
